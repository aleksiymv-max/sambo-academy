# Фактическая стадия судейского курса — 24.10.2026

## Реализовано в коде
- 12 модулей: первый редакционно переработанный модуль и 11 дополнительных.
- 59 отдельных уроков (6 + 53) с нормативными ссылками, ситуациями, разбором и вопросами самопроверки.
- Итоговые тесты доступны через учебный движок; результаты модулей имеют разные индексы `judge:1100` и `judge:1201`–`judge:1211`, исторические результаты не перезаписываются.
- Проверка структуры, JavaScript и браузерных маршрутов включена в GitHub Actions.
- На опубликованной Cloudflare-версии дополнительно проверяются все 12 модулей и открытие выборочных уроков из начала, середины и конца программы.

## Не выполнено / не подтверждено
- Наличие урока **не равно** полному постатейному охвату Правил и всех приложений. Для каждого положения требуется сверка с исходным PDF редакции 14.09.2026.
- 24.10.2026: добавлен отдельный банк из 88 ситуационных вопросов (по 8 на каждый из 11 дополнительных модулей). Они не повторяют вопросы самопроверки; автоматический аудит теперь требует 0 повторов. Это **учебный экзамен, не официальная квалификационная аттестация**. Содержательная сверка ключей с судьёй-методистом остаётся обязательной.
- Изменены индексы результатов дополнительных модулей на `judge:1201`–`judge:1211`. Исторические результаты по индексам `1101`–`1111` не удаляются и не перезаписываются.
- Не проведена полная проверка содержания независимым судьёй/методистом, включая пограничные случаи, жесты и точность изображений.
- Не подтверждена положительная цепочка регистрации/входа реального пользователя → запись результата в Supabase → восстановление результата на другом устройстве.
- Нет подтверждённого Федерацией официального сертификата или присвоения судейской категории.

## Правило статуса
Технический CI `success` подтверждает только покрываемые им сценарии. Курс можно считать **технически интегрированным**, но нельзя объявлять полностью нормативно выверенным, педагогически завершённым или официально аттестующим до отдельного протокола приёмки.
